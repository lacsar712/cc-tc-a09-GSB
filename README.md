# 隧道收敛测缝台

测量员凭**在役铭牌**登记断面收敛毫米值。没有在役铭牌不许报测缝。接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 业务规则

- **无在役牌不报单**：号栏空着、查无此号、或号已退役，一律拒（网页与直连接口同等待遇，不存在“只挡网页”的旁路）。
- **铭牌册专页**：从页眉「铭牌册」进入，分**在役 / 退役**两张表，并给出绑定示例。
- **号只能点在役、且号栏空着才填入**；点到退役号＝**整份退回**（清空整份填报，不留半成品）。
- **号甲绑甲断面**：提交时断面不由前端给，后端在事务内锁住该牌行、以库内读回的号与断面落库，杜绝落库前偷换号/偷换断面。
- **绑定不可改**：铭牌绑上某单后，即便该牌退役，旧单仍留原来的号与断面；应用层无改号入口，数据库行级触发器对直连 SQL 也硬挡改 `plate_code/section`。
- **同号退役后再交→拒**，旧单保留原号。
- **名册改动与履历一次写齐**：入册/退役在同一事务写 `nameplates` 与 `plate_events`，要么都成要么都不成。
- **角色**：测量员（writer）可报送、维护号段、退役；巡检岗（reader）能读名册与记录，不能改册、不能报送。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16（绑定不可改由 PL/pgSQL 行级触发器兜底）

```bash
docker compose up --build
```

健康检查：`GET http://localhost:8201/api/health`

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 公开 | 登录取 token |
| GET | `/api/logs` | 登录 | 测缝单列表（旧单永久留号） |
| POST | `/api/logs` | 测量员 | 报测缝，体：`{plate_code, delta_mm}`；行锁后按在册号/断面落库 |
| GET | `/api/plates?status=active\|retired` | 登录 | 铭牌册（巡检可读） |
| GET | `/api/plates/events?code=` | 登录 | 铭牌履历 |
| POST | `/api/plates` | 测量员 | 新号入册，体：`{code, section}`（名册+履历同事务） |
| POST | `/api/plates/<code>/retire` | 测量员 | 退役（不改任何旧单） |

## 种子

铭牌册：

| 铭牌号 | 绑定断面 | 状态 |
|--------|----------|------|
| J-12180 | K12+180 甲断面 | 在役 |
| J-20050 | K20+050 甲断面 | 在役 |
| J-18040 | K18+040 乙断面 | 退役（留有一张旧单） |

历史测缝单：J-12180 = 1.2 mm 合格；J-18040 = 5.6 mm 超限（退役前旧单，号随单永久保留）。

## 本地无 Docker 验证

```bash
DATABASE_URL=sqlite:///./dev.db python api.py
```
