# 隧道收敛测缝台

测量员凭**在役铭牌**报测缝：登记里程断面与收敛毫米值，接口进程内后台线程认领待判行（不另起 worker 容器），按绝对值是否不超过 3.0 mm 给出合格或超限。页面是 Svelte。

## 铭牌与绑定规则（强制在服务端）

- **没有在役铭牌不许报测缝**：号不在册、形态非法（须形如 `MP-0000`）、已退役，一律拒收，整份退回，不留单据、不写履历。
- **铭牌册专页**：从页眉「铭牌册」点进去，分**在役**、**退役**两张表，并给出绑定示例与铭牌履历。
- **号段维护 / 退役仅测量员**：测量员登记新在役铭牌、对在役号退役；报送时号只能从在役列表里点，网页不允许手填号。
- **退役不可改旧绑定**：铭牌一旦绑过测缝单再退役，旧单仍保留原来的号与断面；退役号不能再交新单，也不能重新登记。
- **名册改动和履历一次写齐**：登记、退役、绑定均在同一数据库事务内写状态 + 履历，任一失败整体回滚。
- **防旁路、防偷换号**：不只挡网页——任何直接调用接口的请求都要过同一道校验；铭牌号服务端归一化后用 `SELECT … FOR UPDATE` 取库内行，落库的号取库内规范号、断面取铭牌册断面（请求体里的断面一律忽略）。
- **巡检岗只读**：能读名册、履历、测缝单，不能改册、不能报送（接口层 403）。

## 技术栈

- 后端：Flask、Gunicorn、SQLAlchemy、进程内认领线程
- 前端：Svelte、Vite、nginx 反代 `/api`
- 数据库：PostgreSQL 16（旧库启动时自动补 `plate_no` 列）

## 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/auth/login` | 公开 | 登录取 JWT |
| GET | `/api/logs` | 登录 | 测缝单列表（含铭牌号） |
| POST | `/api/logs` | 测量员 | 报测缝，body `{plate_no, delta_mm}`，须绑在役铭牌 |
| GET | `/api/plates` | 登录 | 名册，分 `active` / `retired` |
| GET | `/api/plates/events` | 登录 | 履历，可按 `?plate_no=` 过滤 |
| POST | `/api/plates` | 测量员 | 登记在役铭牌 `{plate_no, chainage}` |
| POST | `/api/plates/{plate_no}/retire` | 测量员 | 退役（body 可带 `reason`），不可撤销 |
